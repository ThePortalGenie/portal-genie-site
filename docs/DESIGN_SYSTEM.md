# Portal Genie Design System

**Version:** 1.0  
**Status:** Active  
**Purpose:** Visual Design System

---

# Philosophy

Portal Genie should look like software people trust.

The design should feel:

- Calm
- Premium
- Professional
- Modern
- Simple
- Confident
- Friendly

The website should never feel:

- Corporate
- Busy
- Generic
- Cheap
- Over-designed
- Trendy for the sake of being trendy

Every design decision should reinforce one message:

> Portal Genie is the Customer Experience Layer for Xero businesses.

---

# Design Principles

The website should prioritise:

Clarity before creativity.

Whitespace before decoration.

Hierarchy before colour.

Real product before illustrations.

Outcomes before features.

Consistency before novelty.

---

# Brand Colours

The existing Portal Genie Brand Guide is the source of truth.

Do not invent new primary colours.

Primary Brand Colour

Portal Navy

#112136

This is the dominant colour throughout the website.

Use for:

- Headings
- Navigation
- Footer
- Hero text
- Important sections
- Dark backgrounds

---

Primary Action Colour

Portal Blue

#0077BE

Use for:

- Primary buttons
- Links
- Active states
- Important highlights

---

Secondary Accent

Portal Teal

#00BEB9

Use sparingly.

Used for:

- Icons
- Diagrams
- Success states
- Small highlights

---

Background

Off White

#FAFBFB

Use for most page backgrounds.

Pure white should be reserved for cards and elevated surfaces.

---

Neutral Grey

#B7BCC2

Use for:

Borders

Dividers

Muted UI

Supporting text

---

# Colour Philosophy

The website should feel restrained.

Approximately:

80% White / Off White

15% Portal Navy

5% Accent colours

Colour should guide attention, never overwhelm.

---

# Typography

Primary Typeface

Inter

Fallback

System Sans Serif

Typography should feel:

Simple

Modern

Comfortable

Readable

---

Heading Style

Sentence case.

Never use ALL CAPS for headings.

Keep headings short.

Maximum ideal heading length:

6–12 words.

---

Body Copy

Body copy should be conversational.

Plain English.

No jargon.

Comfortable line spacing.

Never create large walls of text.

---

# Shadows

Use extremely subtle shadows.

Prefer borders over shadows.

Avoid:

Heavy shadows

Glow effects

Glassmorphism

# Cards

Cards should:

Use white backgrounds.

Soft borders.

Rounded corners.

Good spacing.

Little or no shadow.

One clear purpose.

Avoid decorative cards.

---

# Product Screenshots

Real screenshots should be used wherever possible.

The product should be visible within the first screen of the homepage.

Avoid generic SaaS illustrations when a screenshot communicates the idea better.

---

# Diagrams

Portal Genie should own one core diagram.

Xero

↓

Portal Genie

Customer Experience Layer

↓

Customers

This concept should appear throughout the website.

---

# Icons

Use one icon library.

Lucide

Outlined icons only.

Avoid mixing icon styles.

---

# Illustration Style

Minimal.

Geometric.

Simple.

Professional.

Use illustrations only when screenshots cannot explain the concept.

---

# Photography

If photography is used:

Real businesses.

Real people.

Real customer interactions.

Avoid cliché stock photography.

---

# Motion

Motion should help understanding.

Use:

Fade

Slide

Hover

Expand

Avoid:

Parallax

Long animations

Continuous movement

Distracting effects

---

# Forms

Simple.

Friendly.

Minimal.

Clear labels.

Visible validation.

Never rely on placeholder text.

---

# Accessibility

Accessibility is a requirement.

Use:

Keyboard navigation.

Visible focus states.

Accessible contrast.

Semantic HTML.

Reduced motion support.

Readable font sizes.

---

# Mobile First

Every component must work beautifully on mobile.

Desktop enhancements come second.

Never shrink a desktop layout onto a phone.

Design mobile intentionally.

---

# Component Philosophy

Every component should answer:

Does this make Portal Genie feel:

More trusted?

More modern?

More useful?

More premium?

If not, redesign it.

---

# Final Principle

The website should never feel like an accounting website.

It should feel like a premium software platform.

Visitors should think:

"I already trust Xero.

Portal Genie is the missing customer experience layer my business has been looking for."

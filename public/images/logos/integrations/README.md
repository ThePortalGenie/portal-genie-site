# Integration logos (homepage hero)

Approved brand assets for secondary accounting integrations go here.

## Expected files

| Integration | Filename | Notes |
|-------------|----------|-------|
| QuickBooks | `quickbooks.png` | Transparent PNG preferred |
| Sage Business Cloud | `sage-business-cloud.png` | Transparent PNG preferred |

`/images/logos/xero-connected-app-badge.png`

## Wiring

After adding assets, set the corresponding `src` values in `content/homepage.ts` under:

`homepage.hero.integrations.secondary`

Do not invent or recreate third-party logos.
